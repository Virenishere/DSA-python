# DSA Preparation

A structured roadmap to build strong problem-solving skills, master DSA fundamentals, and prepare for technical interviews.

## Goal

- Build DSA fundamentals from scratch using **Python**.
- Understand common problem-solving patterns.
- Solve 120–150 quality DSA problems.
- Improve logical thinking and optimization skills.
- Learn to approach unseen problems independently.
- Understand brute force and optimized solutions.
- Develop fundamental System Design knowledge.

## Phase 4: Interview Preparation & Optimization

**Duration: 45 Days**

For every problem, follow this approach:

### Step 1: Understand the Problem
- [ ] Understand input and output.
- [ ] Identify edge cases.
- [ ] Explain the problem in your own words.

### Step 2: Brute Force
- [ ] Write the brute force solution.
- [ ] Understand why it works.
- [ ] Calculate time complexity.
- [ ] Calculate space complexity.

### Step 3: Optimization
- [ ] Identify inefficient operations.
- [ ] Find a better approach.
- [ ] Implement optimized code.
- [ ] Compare both approaches.
- [ ] Understand trade-offs.

### Step 4: Problem Variations
- [ ] What if the input contains duplicates?
- [ ] What if the array is already sorted?
- [ ] What if the input size is one million?
- [ ] Can memory usage be reduced?
- [ ] Can the problem be solved recursively?
- [ ] Can a different pattern solve it?

### Step 5: Mock Practice
- [ ] Solve problems under time constraints.
- [ ] Explain the approach aloud.
- [ ] Write clean and readable code.
- [ ] Practice without external hints.
- [ ] Revisit previously difficult problems.
